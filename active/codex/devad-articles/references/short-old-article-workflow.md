# Short And Old Article Workflow

Use this workflow for short briefs, thin drafts, rough notes, partial outlines, old articles, and outdated content.

## Short Or Thin Inputs

- Build the topical map from known facts.
- Ask only when a missing fact blocks the output.
- Do not pretend missing product, audience, market, price, competitor, or proof details exist.
- Scale detail to the requested length.
- Use verified examples or broad category attributes when exact values are unavailable.
- Do not pad weak inputs with generic background.

## Missing Numbers

- Never invent exact numbers to satisfy precision.
- Use exact numbers only from source text, user data, product data, or verified research.
- If no reliable number exists, use named examples, concrete attributes, or omit the claim.
- Mark unavailable table values neutrally when a row must be preserved.

## Old Content Refresh

Refresh facts only when the user asks for current, latest, refreshed, updated, or new information.

Verify unstable claims before rewriting:

- prices and plan names
- product features and integrations
- laws, policies, and standards
- rankings and market share
- user counts and company metrics
- dates, benchmarks, and statistics
- AI model names and capabilities
- competitor comparisons

Replace stale facts only with verified current facts. Remove or generalize claims that cannot be verified.

## Citation Policy

- Prefer primary or official sources.
- Cite claims next to the sentence or table row that depends on them.
- Use Markdown links in Markdown output and HTML links in raw HTML output.
- Do not cite unsupported internal claims as if they were verified.
