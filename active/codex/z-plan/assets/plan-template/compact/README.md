# Compact Big-Plan Template Pack

Copy this folder's files into one feature folder; do not create a second plan tree.

1. Start with `PLAN.md` for truth order, scope, and delivery order.
2. Keep `CANONICAL-CHECKLIST.md` beside it as the single live ordered ledger.
3. Add `WORK-ORDER.md` only for a bounded delegated phase.
4. Add `HANDOFF.md`, `DECISION.md`, or `RUN-RECEIPT.md` only for their one purpose.

For a program like `chat-full-migration-1`, split every page and channel into
safe shell/read model, persistence/effect, and independent proof gates. Missing
provider or PostgreSQL proof must not hide a safe local product slice.
