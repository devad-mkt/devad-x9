# Workflow: Landing Page — compact

Handles product pages, home pages, sales pages, feature releases, pricing tiers, and CRO pages. Load `SKILL.md`; load the conversion reference when persuasion or emotion is in scope.

## Page argument

```text
Hero → problem/solution → feature | attribute | operational value
→ proof → fair comparison → primary action
```

### Hero

- Name the primary product/entity.
- State one precise value proposition: `[Product] [verb] [attribute] for [audience] to [measurable outcome]`.
- Put one exact, verified proof metric beside a named source or baseline.
- Use one primary CTA; add a secondary lower-commitment action only when useful.

### Feature and comparison tables

Represent each feature as `Entity | Attribute | Operational Value`. Use concrete channels, counts, limits, integrations, prices, or `—`; never invent values.

Use dimension-rich comparison headers such as `Tool | Supported Channels | Capability | Pricing Basis | Use Case`. Preserve existing rows, columns, order, and unknowns. Compare measurable propositions, not “better/easier” opinions. Add a product row only when the data matches.

## Conversion and voice

When active, lead with audience stakes, translate each feature into a consequence, place proof beside the supported claim, resolve 1–3 genuine objections near the relevant CTA, and repeat one primary CTA in hero, after comparison, and close. Give each image a role, alt text, and caption direction.

Avoid hype unless an attribute proves it: revolutionary, effortless, game-changing, powerful, robust, best-in-class, cutting-edge, world-class, next-generation, industry-leading, trusted by thousands. Persuade through exact metrics, supported types, named integrations, pricing basis, and dated case-study data. Use neutral, technical language.

## QA

- Hero contains one exact metric and named source.
- Feature matrix contains at least five concrete EAV rows when enough data exists.
- One primary CTA is explicit.
- No unsupported hype, features, prices, outcomes, or testimonials.
- Comparison rows/columns remain complete and fair.
