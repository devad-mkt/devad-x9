# Workflow: Report / Audit — compact

Handles market research, competitive audits, executive briefs, whitepapers, benchmarks, and analysis reports. Load `SKILL.md` first.

## Report order

```text
executive summary → methodology/scope → key findings/data tables
→ risk and impact → actionable recommendations → appendices
```

Put the single most important finding in the first sentence. Put 2–3 supporting metrics beside named sources and dates in the first two paragraphs. State dataset names/counts, collection dates, inclusion criteria, tools, limitations, and exclusions in methodology.

## Findings, risk, action

Open each finding with `Entity + measured attribute + exact value + source/date`. Use dimension-rich tables; every cell contains a verified value or `—`, and every table has a source column. Put citations beside claims.

Use severity `Low | Medium | High | Critical`, likelihood `Low | Medium | High`, quantified impact, and one specific mitigation in risk tables. Use recommendations with `P1` urgent, `P2` important, or `P3` monitor; each action has a time bound, quantified expected impact, and hour/day/week effort.

## Style and QA

Use third person, past tense for methodology, present tense for findings, formal neutral language, and no contractions. Synthesize related data instead of repeating it. Never publish unsourced statistics or subjective “best” claims.

- Every metric has source and date.
- Executive summary contains the finding plus 2–3 supporting metrics.
- Methodology states dataset, dates, parameters, tools, and limitations.
- Tables use relational headers and a source column.
- Actions are specific, time-bound, and quantified.
