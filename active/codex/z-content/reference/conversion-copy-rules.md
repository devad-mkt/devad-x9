# Conversion Copy Rules — compact gate

Load this file with the selected type workflow when persuasion, emotion, action, CTA design, or audience decisions are in scope. Technical and data-only work skips it.

## 1. Pre-plan and evidence

Bind the page purpose, one audience, traffic source, awareness, offer/cause, mechanism, benefit, constraints, format, source authority, and one primary action/destination. Ask only when missing information changes risk or outcome; otherwise record a low-risk assumption.

Classify consequential claims before drafting:

| Status | Use |
|---|---|
| VERIFIED | Current primary or owner-approved evidence supports the claim. |
| PROVIDED | The user supplied the claim; independent verification is pending. |
| PLACEHOLDER | The field is visibly marked for later confirmation. |
| DROP | The claim is unprovable, misleading, unnecessary, or outside authority. |

Visual evidence does not prove beneficiary counts, delivery, location, ongoing impact, or fund use. Never invent prices, outcomes, testimonials, urgency, scarcity, guarantees, certifications, or stories.

## 2. Argument and craft

Choose one audience, one big promise or emotional truth, one CTA, one pictureable scene, the proof order, genuine objections, and the image sequence. Structure the argument as:

`stakes → desired change → mechanism → proof → meaning → action`

Lead with a concrete outcome or human stake. Use specific nouns, domain verbs, source-adjacent proof, informative headings, and one idea per section. The reader/customer/cause is the hero; the organization is the credible guide. Keep dignity, agency, cultural fit, and voice. Never expose internal narration or editorial process in public copy.

## 3. CTA and image gates

Show the primary CTA after the first complete reason to act, repeat the same action after major conviction peaks, and close with the same destination. Resolve a real objection beside its CTA. Put broad FAQs and extra details after the main close.

Give each image one or more roles: stakes, context, mechanism, proof, outcome, or close. Track source, rights, consent, date, location, and sensitivity. If context or consent is unknown, prefer non-identifying contextual imagery and report the blocker.

## 4. Editing and ethics

Run these separate sweeps: clarity, voice, so-what, proof, specificity, emotion, friction, and anti-slop. Remove clichés, hedging stacks, fake sophistication, and empty grandeur without mechanically banning useful rhythm.

Make emotional copy vivid but truthful. Signal illustrative scenes with `Imagine...` or `For a family...`; do not present them as case evidence. Avoid humiliation, savior language, guilt threats, fabricated intimacy, shock, false urgency, and guaranteed impact. Use faith language sparingly; verify quotations and never promise divine reward or spiritual outcomes.

## 5. Source ladder and outcomes

Prefer: current organization records and approved facts; current live/authenticated source; supplied official documents; primary public sources; dated snapshots; competitor pages for structure only. Competitor copy is not evidence or text to imitate.

- `PASS`: evidence and brief are sufficient.
- `PASS_WITH_ASSUMPTIONS`: low-risk assumptions are recorded.
- `DEPENDENT_BLOCK`: one claim/section waits while other work continues.
- `STOP`: missing authority, rights, or decision materially changes the result.
