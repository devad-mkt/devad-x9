# Lesson Template

Add or update one entry only after the blocker is solved and verified.

```markdown
## L-NNN — Short reusable failure class

- **Trigger:** Exact repeated symptom.
- **Objective:** User-visible outcome that was at risk.
- **Root cause:** Directly verified cause, not the error message alone.
- **Failed route:** What failed and why it did not prove objective failure.
- **Winning route:** Smallest safe route that succeeded.
- **Hard boundary preserved:** Security, authority, collision, rollback, or
  proof rule that remained intact.
- **Proof:** Exact test/runtime/receipt identity.
- **Do not repeat:** One sentence naming the wasteful pattern.
- **Promote to core:** `NO` unless this recurred and a concise universal rule
  prevents it without widening authority.
```
