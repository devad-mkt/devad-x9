# Use Cases

## Landing Page

Load `assets/landing-page-copy-template.md`. Focus on one audience, promise,
mechanism, proof sequence, and primary CTA.

## Fundraising or Charity Appeal

Load `emotional-conversion.md`, `image-storytelling.md`, and
`assets/fundraising-page-template.md`. Make the need imaginable, the response
tangible, and the donation path easy without weakening dignity or evidence.

## Homepage

Clarify category, audience, primary value, and the most important next step
above the fold. Route secondary intents later.

## Product or Service Page

Translate features into outcomes, show the mechanism, differentiate with
facts, and answer real purchase objections. The company is not the hero.

## Rewrite

Preserve facts and successful phrases. Reorder before rewriting every line.
Run the eight editing sweeps and return a complete replacement.

## Audit

Inspect the rendered experience when possible. Evaluate message match,
attention order, emotion, credibility, CTA visibility, friction, images,
mobile scanning, and internal-language leakage.

## HTML or CMS Preview

Use BUILD mode. Mirror only supported editor blocks. Prefer semantic HTML,
existing CSS, and real assets. Validate paths, images, links, headings,
desktop, and mobile.

## Short-Form Ads or Email

Adapt the message to channel length. Surface the email goal and CTA early. Keep
an ad's promise and evidence close; do not compress away truth conditions.
