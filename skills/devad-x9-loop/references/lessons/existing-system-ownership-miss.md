# X9 Loop Existing-System Ownership Miss

## Loop Lesson

The Controller must not admit a Work Order that treats a capability as new
without current source-backed absence. The context capsule binds UI/settings,
server authority, persistence/runtime, accepted Git lineage, tests, the exact
gap, and `REUSE`, `EXTEND`, `NEW`, or `REPLACE_AUTHORIZED`.

Graphify, Sheets, sessions, memory, RAG, and external graphs may discover
candidates but cannot close relations. Revalidate exact source references
before Work Order creation and dispatch. A missing relation blocks only the
affected task. Do not claim this lesson is enforced until schema, validator,
migration, rollback, and red/green regressions pass on installed bytes.
