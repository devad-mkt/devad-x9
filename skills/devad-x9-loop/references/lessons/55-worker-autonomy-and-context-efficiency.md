# Worker Autonomy And Context Efficiency

Bug class: routine safe actions were narrated as approval requests, recoverable
environment steps became micro-Work-Orders, and identical reviews resent full
context. A current bounded Work Order is already authority for in-scope local,
read-only, and reversible work with no new external effect.

Keep one independently accepted outcome in one Work Order and record failed
routes as canonical evidence rather than a mutable integer. After two distinct
approaches, one registered THINKER review may be admitted; the same Work Order,
review class, evidence question, and staged tree reuse the durable verdict.
Use the manifest-bound execution sitemap and signal-only wakes so a resumed
Worker rereads durable packets instead of receiving copied history.

Follow-up: outbound Worker questions require the explicit five-way admission
classification. Missing admission continues locally. A concrete THINKER block
is a local defect-correction cycle, not an owner blocker; host-wide interception
of arbitrary Codex messages is not available and must not be claimed.
