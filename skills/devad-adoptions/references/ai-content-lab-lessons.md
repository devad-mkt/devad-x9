# AI Content Lab And MagicAI Lessons

Use this reference for AI, MagicAI, ai.devad.io, Content Lab, Brand Voice, Writer, Documents, AI pricing, token packs, and Laravel AI provider adoption.

## Failure To Prevent

The first AI Content Lab scaffold was not production parity:

| Feature | Adoption | Main reason |
| --- | ---: | --- |
| Writer | 35% | Three hardcoded templates instead of full AI Writer marketplace and workbook behavior |
| Brand Voice | 25% | Flat voice profile instead of company plus products/services model |
| Documents | 25% | Simple saved draft editor instead of My Documents plus workbook/editor surface |

Do not repeat this pattern. A compact foundation is not an adoption.

## Correct Fix Order

Use this order for AI Content Lab recovery:

1. Brand company plus products/services model.
2. Writer template marketplace.
3. Article generator workbook vertical slice.
4. Documents manager.
5. Rich workbook editor.
6. Live provider plus token wallet.

Do not wire live generation or credit debit before source parity, dry-run behavior, workspace isolation, and action contracts are proven.

## Writer Requirements

Before exposing Writer as adopted, prove:

- AI Writer template marketplace/list with categories, filters, favorites, and generator links,
- per-template dynamic workbook fields from source evidence,
- include-brand toggle,
- company and product/service binding from Brand Voice,
- bulk generation and number-of-results controls where source has them,
- language list, creativity, maximum length, tone/custom tone, provider/model selector,
- remaining credits/cost preview,
- generate action backed by Laravel AI and unified token wallet when live mode is enabled,
- dry-run that does not call providers or debit credits,
- document/workbook output with editor handoff.

For the article generator workbook, source parity must include at minimum: Include Your Brand, Select Company, Select Product/Service, Generate Bulk Posts, Number of Results, Article Title, Focus Keywords, Language, Maximum Length, Creativity, Tone of Voice, custom tone, Other Models, Generate, credits/cost display, document title/body, and editor actions.

## Brand Voice Requirements

Use the ai.devad.io model:

- Company step: company name, industry, description, website, tagline, tone, target audience, brand logo/file, brand color, specific instructions.
- Products/Services step: repeatable rows with name, type, key features, add/remove behavior.
- Manage Voices/index view with edit/delete/select flows.
- Writer must select company/product, not just a flat "brand voice" name.

## Documents Requirements

Before exposing Documents as adopted, prove:

- My Documents route with table/grid,
- folders and New Folder modal,
- filters for All, Favorites, Text, Image, Video, Code when in scope,
- sort, row checkboxes, bulk actions, favorite, delete, options,
- type/date/cost/action columns,
- single workbook route,
- rich editor toolbar with undo, redo, copy/download, rewrite, formatting controls,
- Open with AI Editor and share/export handoff where source has it.

## Visibility Rule

No visible AI Content Lab tab should ship unless it is usable end-to-end and matches captured source evidence. Hide incomplete tabs. Report `PARTIAL` instead of polishing a fake workflow.

## Pricing And Token Packs

Money-sensitive AI pricing and token packs require separate proof:

- admin-only configuration,
- workspace-owned shared credits,
- stackable non-expiring token packs by default,
- cost estimate before generation,
- debit after final usage where possible,
- row locks, idempotency keys, ledger rows, and insufficient-balance tests,
- no user-facing admin config.
