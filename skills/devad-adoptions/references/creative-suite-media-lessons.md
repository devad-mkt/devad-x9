## 1. Product Boundary

- Creative Suite is the purchased/reference host experience.
- Image Agent is current-Core design, annotation, template autofill,
  API/CLI/MCP and render-job capability.
- Video Agent is its own timeline, media, audio and rendering product.
- Do not create an incomplete Canva clone or transplant the predecessor UI.

## 2. Historical Decisions

Preserve product semantics, not obsolete implementation:

- Stable template field keys remain useful.
- Raw Konva attributes or predecessor scene JSON are not automatically the
  target persistence schema.
- Historical Konva is only an engine candidate.
- Laravel 10, Blade, Alpine, Passport, PhotoStudio, loopback/shared-secret
  workers, fake HTTP rendering and private Node topology require current-Core
  decisions.

Use the exact owner-named historical task as reviewer at plan, pre-code and
post-result checkpoints.

## 3. Required Evidence

Give independent denominators to home/start modes, canvas, layers/pages,
templates/artboards/variables, image generation, AI Designer, Annotation,
assets, revisions/recovery/export, responsive/accessibility/performance,
API/CLI/MCP/jobs, settings/credits/permissions, security, and clean-room
Laravel/React adoption.

AI Designer and Annotation each need visible/hidden/error states, editable
proposal contracts, safe screenshots, addon identity, native owners and tests.
Marketplace prose or registration hooks do not prove installed source.

## 4. Engine and Rendering Decisions

Compare separately:

1. browser editor/canvas engine;
2. engine-neutral persisted document;
3. background renderer;
4. AI provider;
5. autofill/API/CLI/MCP.

React-Konva, Polotno or another SDK answer only the editor question. Canva
Autofill, Placid, Shotstack, JSON2Video and similar services belong to
automation/rendering comparisons.

Bind browser, app server and render-worker CPU/RAM/concurrency before accepting
"lightweight."

## 5. Current-Core Adoption

Use current Laravel, Inertia, React, Tailwind, Wayfinder, workspace policies,
assets, Laravel AI/model policy, queues, credits, API keys, MCP and tests.

Before code, inspect admin plus user/workspace settings; select component
sources/licenses; freeze document schema; define revisions/conflicts and job
state machines; specify security/receipts; and write 5-15-file Work Orders with
no unresolved architecture.

## 6. Image and Video Separation

Do not infer video support from an image canvas. Video evidence additionally
covers tracks, clips/scenes, trim/split/order, transitions/keyframes/speed,
audio/voiceover/captions, playback/timeline zoom, codecs/resolution/frame rate,
render/cancel/retry/callbacks, and bulk media variables.

Canva image/text Autofill limitations do not define Video Agent.

## 7. Acceptance

Reject `READY` unless every requirement maps to evidence, owner, decision and
proof; identities are explicit; browser/source/settings reconcile; schemas,
states, security and performance are fixed; dependencies are accepted; current
owners/tests are exact; reviewer gates pass; and a lower model has no
architecture left to choose.
